Backend flow
Request
   ↓
Route
   ↓
Middleware
   ↓
Controller
   ↓
Service
   ↓
Repository
   ↓
MySQL
Responsibility
Route       → URL/API endpoint
Controller  → req/res
Service     → business logic
Repository  → SQL/database
Validation  → validate input
Types       → TypeScript types
Middleware  → auth/role/error handling
